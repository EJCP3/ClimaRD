# Reglas del Proyecto ClimaRD

## Gestor de Paquetes
- **USAR SIEMPRE `pnpm`**: Para todas las operaciones en el frontend (instalación de paquetes, dependencias, ejecución de scripts, compilación `pnpm run build`, servidor de desarrollo `pnpm dev`, etc.), se debe utilizar estrictamente `pnpm`.
- **NUNCA** utilizar `npm` ni `yarn`.
